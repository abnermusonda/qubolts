# Code of Conduct

Qubolts is a professional, welcoming community. We expect everyone who
participates, in issues, pull requests, discussions and events, to:

* be respectful and assume good intent;
* give and accept constructive technical criticism gracefully;
* focus on what is best for the project and its users;
* never harass, insult or demean anyone, publicly or privately.

Unacceptable behavior includes harassment, discriminatory language, personal
attacks, and publishing others' private information without consent.

Maintainers may remove, edit or reject contributions that violate this code and
may ban contributors for repeated or serious violations.

To report a concern, open a private security advisory on GitHub or contact the
maintainers listed in the repository. Reports are handled confidentially.

This code is inspired by the Contributor Covenant (https://www.contributor-covenant.org).
Maintainers may adopt the full Contributor Covenant text in its place.
